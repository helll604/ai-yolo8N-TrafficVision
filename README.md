# AI Traffic Vision 🚦

AI-based intelligent traffic monitoring system using 
YOLOv8, DeepSORT, and ESP32-CAM for realtime vehicle detection and counting.

## Features

- Realtime vehicle detection
- Vehicle counting system
- ESP32-CAM streaming
- DeepSORT tracking
- YOLOv8 object detection
- FPS monitoring
- Automatic reconnect system
- Traffic analytics overlay


## System Architecture

ESP32-CAM
   ↓
Video Streaming
   ↓
YOLOv8 Detection
   ↓
DeepSORT Tracking
   ↓
Vehicle Counting
   ↓
Realtime Dashboard


## Technologies Used

- Python
- OpenCV
- YOLOv8
- DeepSORT
- PyQt5
- NumPy
- ESP32-CAM
